## 0. 结论：挡住 1.0.0 的不是功能

**PRD 正文里计划要做的事项已经全部落地。** `1009_01_uiux-revamp-plan.md` §8 的总验收清单 23 条里，
只有 3 条还是空的（VoiceOver 一条已由用户明确跳过），其余全部打勾 —— 包括三种视图、四向拖拽、
⌘C/⌘V 跨栏、Quick Look、预览窗格、设备端写操作、设备端存储卷、可观测性。

挡住 1.0.0 的是另外三类东西，按分量排序：

| 类 | 是什么 | 谁做 |
|---|---|---|
| **A 验收** | 绝大部分交互与设备端行为只做到「编译通过 + 有判据」。**本机不能截图、不能模拟点击**，所以这一整块从未被人眼看过 | 只能人来，但**清单可以由我写** |
| **B 发布工程** | 仓库**没有 LICENSE**、`NSHumanReadableCopyright` 是空串、版本号还是 `0.1.0`、没有 CHANGELOG | 一部分我能做，**LICENSE 选型与法务必须你定** |
| **C 功能缺口** | 剩下 6 项真缺口（下表），全部来自 PRD §4 的 P1 或「未实现」栏 | 我能做 |

**所以「到 1.0.0」的正确含义是「敢承诺的那一天」，不是「功能写满的那一天」。**
现在离「敢承诺」差的不是代码量，是**证据**。

### 0.1 扫查时顺手修掉的一处文档错误（会影响判断，所以记在这里）

`README:393` 与 `docs/1011_01_device-acceptance-report.md:394` 都写着这些回归守卫
「**不会**在 CI / 构建时自动跑」。**实际 CI 从建起来那天就一直在跑**
（`.github/workflows/ci.yml:72` → `scripts/check-all.sh`）。错的方向是**低估**现有防线，
所以下文的 C5 也随之改写：真缺口只是「本地构建不跑」，不是「CI 不跑」。两处已一并更正。

### 0.2 现在的答案：机器全绿，剩 4 条人工项（2026-10-11 深夜）

`scripts/check-release.sh` 是本文档 §3 那份清单的可执行版本。拿一个真的 **1.0.0 候选**
（构建 → 四道守卫 + shell 检查 → 公证 app 与 DMG 双双 `Accepted` → staple → 打包）去撞它：

```
PASS 26 · FAIL 0 · 人工项 4
```

**机器能判的全部达标**，B 类里 B1/B3/B4/B5/B6 已关闭，只剩 **B2（法务）**。
那 4 条人工项是：法务确认 · 声明范围的实测覆盖 · 交互层人工验收 · 干净 VM / Translocation / 性能基线。

⇒ **结论：技术上随时可以发 1.0.0；「能不能发」现在只剩一个非技术问题 —— 法务对
`NOTICE.txt` §3.5 的确认。** 范围怎么声明已经拍板：**按现状发，README / PRD §5 /
发行说明三处如实写明「已在 Android 10 验证；11–16 未验证但未发现不兼容」**。

## 1. 先说清楚 1.0.0 在承诺什么

PRD §5 声明支持 **Android 10–16**（macOS 14+ / Apple Silicon 另行声明）。而实测记录是：

| 环境 | 状态 |
|---|---|
| macOS 14+ / Apple Silicon | 本机开发环境，日常在跑 |
| **Android 10** | 真机测过一轮（`0926_03`，华为 DVC-AN20） |
| **Android 11–16** | **一个都没测过** |
| API 37.2（Android 17） | 模拟器测过两轮，**但它落在声明范围之外** |

⇒ 声明支持范围里有 6 个版本**零证据**，而其中 11+ 恰好是权限与 MediaStore 行为变化最剧烈的区间
（`Android/data` 不可写、MediaProvider 转 FUSE、`cmd media_scanner` 取代广播）。
**这是 1.0.0 最大的一条风险，且它不能用代码修，只能测。**

> 可选的诚实出口：把 1.0.0 的**声明范围**缩到「Android 10 + 13 + 15 已验」（PRD §19 原本就要求
> 「至少 3 个真实版本」），把其余版本写成「未验证但未发现不兼容」。这与 §5 的现状并不冲突 ——
> §5 写的是**目标**，不是已验范围。这条要你拍板。

## 6. 建议的 ticket 队列

按「**先解锁验收、再补硬门槛、最后补功能**」排 —— 因为验收项最多、最阻塞，而且它一旦解锁，
后面每一次改动都能立刻被看见。

```
R-1  出「人工验收清单」                                 ✅ 本文 §8
R-2  把 check-all.sh 接进 build.sh 收尾（C5）             ← 低成本，本地也能自动过回归
R-3  LICENSE + 版权字段 + CHANGELOG（B1/B3/B5）          ✅ 已完成（MIT）
R-4  PRD §28 清单落成 scripts/check-release.sh（B6）     ✅ 已完成
R-5  SpikeView 去留 + 清死代码（C4）
R-6  照片图库网格缩略图（C1）                            ← UI 改动，先出图
R-7  排序方式菜单（C2）+ Tab 三段循环（C3）
R-8  三版本设备端验收（A1/A6/A7）                        ← 需要你先装镜像
R-9  干净 VM + Translocation + 性能基线（A3/A4/A5）
R-10 1.0.0 发版：release-local.sh 1.0.0 --publish
```

**并行条件**：R-8 / R-9 需要你在别的机器或真机上动手；R-1 ~ R-7 我都能独立推进。
**唯一真正的串行点是** R-10 —— 它要求 A1–A5 有结论，而 A1 要求至少一个声明范围内的真实 Android 版本被测过。

若要**最快**到 1.0.0：只做 R-1 / R-2 / R-3 / R-9 / R-10 + A1 的最小版本（在**一个**声明范围内版本上
把媒体入库测通），功能缺口全部推到 1.0.x。这条路的代价是 1.0.0 的「功能完整度」较低。

## 8. 附录：人工验收清单（R-1 的产物）

> 用法：打开 app，逐条走一遍，把 `[ ]` 改成 `[x]` 或 `[!]`（附一句现象）。
> 带 ⚠️ 的是**本轮新增、从未被人眼看过**的项。全部走完约 20 分钟。

### 8.1 三种视图与导航

- [ ] 列表视图：点列头排序（名称 / 种类 / 大小 / 修改日期），再点一次反向；设置里关掉「文件夹排在最前」后顺序变化
- [ ] 分栏视图（⌘2）：铺列、点文件夹展开下一列、**列首不会再跳回第一列**、底部路径栏可点
- [ ] 分栏视图的行内**类型图标是否出现**（`willDisplayCell` 无承诺，退化为纯文本行不算缺陷）
- [ ] 网格视图（⌘3）：缩略图出图、⌘+ / ⌘- 改变一屏能放几个、点空白处取消选择
- [ ] ⚠️ 网格视图：方向键移动选择、**↑ / ↓ 是否与屏幕上的一整行对齐**（不对齐说明列数回报与实际铺列不一致）
- [ ] ⚠️ 网格视图：敲字母跳转；连敲同一字母在命中项之间轮转；停手 0.8 秒后再敲重新开始
- [ ] ⚠️ 网格视图：⇧+方向键扩展选择；移动到屏幕外的条目时**视图会自动滚过去**
- [ ] ⚠️ 网格视图：⌘+ / ⌘- 放大缩小后**再按 ↑ / ↓ 仍然对齐**（这条专门验「列数回报」那条补丁）
- [ ] ⚠️ 网格视图：按一下方向键再按一次鼠标点选，⇧+方向键扩展的起点是否正确
- [ ] ⇧⌘X 交换两侧后，⌘⌥← / ⌘⌥→ 是否仍按**视觉左右**走

### 8.2 键盘与 Quick Look

- [ ] Tab / ⇧Tab 在两个窗格间循环；焦点态有**描边 + 标题加粗**（不能只靠颜色）
- [ ] 空格 Quick Look：**第一次打开、第二次收起**；面板内方向键切换条目、Esc 关闭
- [ ] 面板开着时按 Tab **不会**把焦点搬到另一窗格
- [ ] 删除确认弹窗弹着时按空格**不会**切换背后的 Quick Look
- [ ] 在搜索框 / 重命名框里：空格与 Tab 保持文本语义；⌘C/⌘V/⌘X/⌘A/⌘⌫ 恢复文本语义；**回车是「提交」而不是「重命名」**
- [ ] ⚠️ ⏎ 重命名：单选设备端条目 → 键位与「显示 → 重命名…」**两条入口都进得去**；预填原名；Esc 取消
- [ ] ⚠️ ⏎ 重命名：改成已存在的名字（**含只有大小写不同**）→ 提交前被拒并给出说明
- [ ] ⚠️ 分栏视图里按 ⏎ **什么都不该发生**（这是刻意的）
- [ ] ⚠️ ⏎ 在 Mac 窗格按 **什么都不该发生**（本地改名交给 Finder）

### 8.3 传输

- [ ] 上传：Mac 窗格选中 → 工具栏 / ⇧⌘U / ⌘C-⌘V 三条路径都能传
- [ ] 下载：设备窗格选中 → 工具栏 / ⇧⌘S / ⌘C-⌘V 三条路径都能传
- [ ] 从 Finder 拖文件进窗口 → 上传；从 Mac 窗格拖到设备窗格 → 上传
- [ ] 拖到不可写目录（`Android/data` 等）→ **显示禁止光标**，不是静默失败
- [ ] ⚠️ 设备窗格内拖动 → 移动；⌘X 后切目录 ⌘V → 移动
- [ ] ⚠️ 移动 / 重命名遇到同名（含大小写不同）→ **整批拒绝并报出冲突名**，不是覆盖
- [ ] 传输面板：速度与 ETA、失败行常驻「重试」与「查看原因」、可固定
- [ ] ⚠️ 隐藏文件开关（⇧⌘.）**两侧同时生效**：设备窗格里的 `.nomedia` 会跟着显隐

### 8.4 引导与空态（PRD §17.1）

- [ ] 无设备时：连接引导卡片有图、有步骤、有「重新检测」
